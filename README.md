# PASMA project site

Companion website of the ISMIR 2026 paper *Digital Existence as Ontological Intervention: Backstage Networks in Postwar Taiwanese Popular Music* (Cheng, Chang, Yang and Su), published at **https://bkwmt.github.io/PASMA/**.

PASMA (the Private Archive of Scanned Music Artifacts) is a dataset of backstage credits reconstructed from the liner notes of 1,122 Taiwanese vinyl records (1957–1991). The dataset itself is **not** in this repository and is not publicly downloadable; researchers may request access by email (see the Dataset page). This repository holds only the static site: historical context written to answer the paper's reviewers, a page on the key people in the network, the dataset documentation, and the paper with its poster and video.

## Layout

```
content/      page sources: *.md with YAML front matter; people.yaml; references.yaml
tools/        build.py (Markdown → HTML), check.py (gatekeeper), deploy.sh, site.yaml, manifest.yaml, style.css, tests/
assets/       built images (downscaled), PDFs, video, portraits   ← generated by build.py, committed
*.html        built pages                                         ← generated, committed
```

## Build

```bash
uv venv --python 3.13 .venv && uv pip install --python .venv/bin/python -r requirements.txt   # once
.venv/bin/python tools/build.py          # content + manifest → *.html + assets/
.venv/bin/python tools/check.py          # must pass before deploying; --links also tests external links
.venv/bin/python -m unittest discover -s tools/tests
python3 -m http.server 8013              # preview at http://127.0.0.1:8013/
```

Numbers in the text are never typed by hand: `{鍵}` placeholders are filled from the paper's `numbers.json` (see `tools/manifest.yaml`). Citations are written `[@key]` and resolved against `content/references.yaml`; an unknown key stops the build. `check.py` refuses a site that contains any `data/` directory, any JSON other than the asset lock file, any file whose name looks like dataset material, external scripts or stylesheets, broken links or anchors, or files over 10 MB that are not whitelisted.

## Deploy

`tools/deploy.sh "message"` builds, checks, commits, pushes to `main` and verifies the live site. GitHub Pages serves the repository root (`.nojekyll` is present).
